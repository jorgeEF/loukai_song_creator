# Loukai song creator by jeF  

Requerimientos:    
1. Python 3  
2. Demucs:    
`pip install -U demucs` 
3. Node    

Instrucciones:    
1. Descargar repositorio de la app.    
2. Ejecutar npm install en el directorio raiz de la app.
3. Ejecutar: `npm start`  
4. Abrir navegador en http://localhost:3000/  
5. Generar canciones!
